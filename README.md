# 🐾 We Care - Pet Care Landing Page

Uma demo de landing page moderna e responsiva voltada para serviços de cuidados com pets. Este projeto foi desenvolvido para construir uma interface limpa, amigável e completamente adaptável a dispositivos móveis.

## 💻 Sobre o Projeto

O **We Care** é uma interface de apresentação (Landing Page) que exibe a seção principal ("Hero Section") de um serviço veterinário ou de adoção. O layout foi estruturado com foco em responsividade, garantindo que a experiência do usuário seja fluida tanto em computadores quanto em smartphones.

## ✨ Funcionalidades

- **Design 100% Responsivo:** O layout se reestrutura perfeitamente para telas menores através de *Media Queries*.
- **Alinhamento com Flexbox:** Organização eficiente, fluida e moderna dos elementos da tela.
- **Tipografia Customizada:** Integração com o Google Fonts utilizando a família tipográfica *Montserrat*.
- **Estrutura Semântica:** Uso das tags semânticas do HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`).

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação e semântica web.
- **CSS3:** Estilização, Flexbox e responsividade.
